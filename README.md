# Java Product Catalog and Shopping Basket

![Java CI](https://github.com/aaminter/dz202_oop/actions/workflows/ci.yml/badge.svg)

Консольная учебная модель каталога товаров и корзины покупателя.

## Компоненты
- `Product`: модель товара с названием и ценой;
- `ProductBasket`: добавление, удаление, проверка наличия, очистка и расчёт стоимости корзины;
- `SearchEngine`: поиск товаров по части названия без учёта регистра.

## Технологии
Java, ООП, инкапсуляция, композиция, `List`, `LinkedList`, итераторы и строковый поиск.

## Запуск
Требуется JDK. Запустите класс `org.skypro.skyshop.App`.

Учебная консольная модель без веб-интерфейса, постоянного хранилища, авторизации и платёжной интеграции.
